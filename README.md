# 예약 브라우저 캡처

Chrome 또는 Edge의 Manifest V3 확장 프로그램입니다. 웹사이트 탭별로 매시 특정 분 또는 매시 N분 간격의 PNG 캡처를 예약합니다. 활성화되지 않은 탭에도 디버거를 연결하여 캡처를 시도합니다.

## 설치

1. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**에서 이 폴더를 선택합니다.
3. 캡처할 웹사이트들을 연 뒤 확장 프로그램 아이콘을 클릭합니다.
4. 각 탭의 접두어, 파일 이름 형식, 저장할 하위 폴더, 캡처 시간을 지정하고 저장합니다. **지금 캡처**로 먼저 확인하세요.

## 저장 위치와 이름

- 자동 저장 경로는 브라우저 기본 다운로드 폴더의 하위 폴더입니다. 절대 경로는 확장 프로그램 다운로드 API에서 지원하지 않습니다. 다른 위치가 필요하면 브라우저 설정의 기본 다운로드 위치를 바꾸세요.
- 설정에서 **1. 다운로드 폴더 선택**으로 브라우저 설정과 동일한 다운로드 폴더를 선택한 뒤 **2. 하위 폴더 선택 / 만들기**로 이동하거나 새 폴더를 만들 수 있습니다. 확장 프로그램은 브라우저의 실제 다운로드 위치를 확인할 수 없으므로 첫 번째 폴더를 정확히 선택해야 합니다.
- 브라우저 설정에서 매번 저장 위치를 묻는 옵션을 꺼야 무인 저장됩니다.
- `{prefix}_{YY}.{MM}.{DD} {HH}-{mm}` 예: `aa모니터링_24.11.26 12-00.png`. Windows는 파일 이름에 `:`를 허용하지 않습니다. 같은 이름의 파일은 덮어쓰지 않고 번호를 붙입니다.
- 날짜/시간은 캡처 실행 시점의 컴퓨터 현지 시간입니다.

## 주의사항

- 브라우저와 컴퓨터가 켜져 있어야 합니다. 절전, 예약 지연, 메모리 절약으로 폐기된 탭, 페이지 특성에 따라 캡처가 실패하거나 지연될 수 있습니다. 시스템 화면 전체가 아닌 웹페이지의 현재 보이는 영역을 캡처합니다.
- Chrome/Edge 내부 페이지 및 확장 프로그램 페이지는 지원하지 않습니다. 탭이 닫히거나 다른 사이트로 이동하면 다시 설정해야 합니다. 브라우저를 재시작하면 탭 식별자가 바뀔 수 있으므로 모든 일정을 중지하며 탭 재지정 및 재활성화가 필요합니다.
- 각 브라우저 프로필에 별도로 설치 및 설정해야 합니다. 서로 다른 Chrome/Edge 프로세스는 각자의 확장 프로그램이 캡처합니다.
- 디버거 권한을 사용하므로 캡처 중 디버깅 안내가 표시될 수 있고, 대상 탭에서 개발자 도구 등 다른 디버거가 연결되어 있으면 실패할 수 있습니다. 확장 프로그램 설정의 최근 상태에서 확인하세요. 다운로드 시작은 파일 쓰기 완료를 뜻하지 않습니다.
- **탭 표시**는 활성 탭을 변경하지 않고 대상 탭 제목 앞에 표시를 잠시 깜빡입니다. 사이트가 제목을 바꾸거나 브라우저가 백그라운드 탭을 제한하면 표시가 늦어지거나 잘 보이지 않을 수 있습니다.
- 사이트 화면을 저장하므로 민감한 정보가 이미지에 포함될 수 있습니다.
