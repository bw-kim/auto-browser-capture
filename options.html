01 / CAPTURE SETUP

새 캡처 일정

탭 표시를 누르면 해당 탭 제목에 표시가 잠깐 깜빡입니다. 확인한 뒤 접두어에 대상 이름을 적어 주세요.

사용 가능: {prefix}, {YYYY}, {YY}, {MM}, {DD}, {HH}, {mm}, {ss}. Windows에서 : 문자는 파일 이름에 사용할 수 없어 시간 구분에 -를 사용합니다.

먼저 브라우저 설정에 지정된 기본 다운로드 폴더를 선택한 다음, 저장할 하위 폴더를 선택하거나 새로 만드세요. 실제 저장은 브라우저의 기본 다운로드 폴더를 기준으로 합니다. 자동 저장을 위해 ‘다운로드 전에 각 파일의 저장 위치 확인’을 꺼주세요.

예: 매시 0분은 정각, 15분 간격은 매시 00·15·30·45분입니다. 예약은 정확히 해당 시각을 보장하지 않으며 컴퓨터가 절전 중이면 지연될 수 있습니다.
